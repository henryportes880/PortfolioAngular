# 📌 Portfólio em Angular

Este projeto é um portfólio pessoal desenvolvido com **Angular** e **Angular Material**, com o objetivo de praticar a criação de interfaces modernas e componentes reutilizáveis.

---

## 🚀 Sobre o projeto

O portfólio apresenta informações básicas sobre mim, organizadas em seções:

- Sobre mim  
- Projetos  
- Contato  

O layout utiliza o componente `mat-list` do Angular Material para estruturar o conteúdo de forma simples e organizada.

---

## 🛠️ Tecnologias utilizadas

- Angular  
- Angular Material  
- TypeScript  
- HTML5  
- CSS3  

---

## 📦 Ambiente (reprodutível)

Para garantir compatibilidade, utilize as seguintes versões:

- **Node.js:** 20.x.x  
- **npm:** 10.x.x  
- **Angular CLI:** 17.x.x  

> ⚠️ Recomenda-se usar versões próximas às indicadas para evitar problemas de compatibilidade.
